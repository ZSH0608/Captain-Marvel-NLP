# Captain Marvel — MomentJump

NLP 课程大作业 · Track B（Demonstration）· Team Captain Marvel

**MomentJump**：面向通用网络视频的自然语言语义检索与时间戳定位系统。
输入自然语言，直接跳到视频里"讲某个知识点 / 某句台词 / 某个进球"的那一秒。
